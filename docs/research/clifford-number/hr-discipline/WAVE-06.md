# Clifford Number HR disciplinary-process Wave 06

Wave 05 classified six counterpower instruments by timing and executable depth. Wave 06 asks the next question:

```text
when counterpower enters,
what actually changes?
```

The answer is divided into eight non-interchangeable effects:

```text
evidence and logic access
processing or adverse-action pause
individual restoration
worker compensation
feature or use retirement
workflow or policy revision
model, threshold, or data revision
follow-up verification and collective memory
```

The governing rule is that a public remedy must remain attached to the object it changed. An explanation is not restoration. A regulator fine is not worker compensation. Restoring one worker is not system revision. A vendor-announced redesign is not independent implementation verification. A published follow-up is not survivor-bias reconciliation.

## Effect matrix

`COUNTERPOWER-EFFECT-MATRIX.json` contains exactly forty-eight cells: six cases multiplied by eight effect types. A cell may be `recovered`, `partial`, `blocked`, or `not_applicable`.

`Recovered` means the public record makes the effect observable within its stated limits. It does not establish completeness, legality, intent, universal effectiveness, or a complete worker-to-system causal chain.

## Remedy ladder

```text
signal visible
→ evidence preserved
→ counterpower actor authorised
→ processing or action paused
→ reason and context joined
→ decision corrected
→ individual restored
→ worker compensated
→ system revised
→ implementation and population reconciled
```

A later stage cannot be manufactured from an earlier one. In particular, money paid to a regulator is not money paid to a worker.

## Interpretive law

Counterpower is not measured by how many people attended a meeting. It is measured by what the institution was forced to expose, stop, restore, compensate, retire, revise, verify, and remember.

A system that pays a fine but does not repair workers has not completed worker compensation. A system that restores one worker but preserves the same classification logic has not learned. A system that announces a redesign but does not permit independent verification has not proved implementation. A system that validates only on workers who remained cannot establish what its earlier decisions suppressed.
